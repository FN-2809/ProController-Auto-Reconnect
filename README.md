# ProController-Auto-Reconnect
Using btpair from Bluetooth Command Line Tools with batch script to automate windows reconnecting issue with Pro Controller controller in bluetooth mode.

1. Download and install Bluetooth Command Line Tools: https://bluetoothinstaller.com/bluetooth-command-line-tools (make sure to add it to path)

2. If you run the script make sure to press the pairing button.

3. Windows will show a pop up and ask if you want to connect your device (Pro Controller). Click allow.
